The 5 DL modules
Module 1
Skin analysis
ResNet50 / U-Net
Detects acne, redness, dark spots from face photo. Outputs severity scores per concern.
Module 2
Ingredient reading
BioBERT
Reads ingredient text. Understands what each ingredient treats and how it works.
Module 3
Ingredient graph
GAT / GraphSAGE
Models ingredient relationships — synergies, contraindications, irritation risks.
Module 4
Safety classifier
MLP
Flags unsafe ingredient combos for your skin type. Filters risky products out.
Module 5
Fusion + ranking
MLP
Combines all module outputs. Ranks products by effectiveness + safety score.
Datasets used
  • ACNE04 — acne severity levels
  • Skin condition dataset — acne, redness, spots
  • Open Beauty Facts — product ingredients
  • Kaggle cosmetics — ingredient-concern mapping
  • CosDNA + EWG — safety labels (self-curated)
Tech stack
  • PyTorch — all DL models
  • HuggingFace — BioBERT
  • PyTorch Geometric — GNN
  • Kaggle Notebooks — training (GPU)
  • Google Colab — experiments
